# Learning Linux from Open GitHub Resources

These links lead to third-party material. The route and exercises below are independently authored; **nothing has been copied** from the linked projects.

| Open reference | What to learn | Suggested practice |
|---|---|---|
| [Linux Upskill Challenge](https://github.com/livialima/linuxupskillchallenge) | CLI and remote system fundamentals | Follow selected exercises in a disposable VM |
| [Linux Journey](https://github.com/labex-labs/linuxjourney) | Filesystems, process concepts, networking | Explain each concept in your own words |
| [The Art of Command Line](https://github.com/jlevy/the-art-of-command-line) | Command-line patterns | Verify commands using official manuals |
| [tldr-pages](https://github.com/tldr-pages/tldr) | Task-based CLI examples | Cross-check with `man` or `--help` |
| [GNU Bash Manual](https://www.gnu.org/software/bash/manual/) | Shell syntax and quoting | Test safe scripts with known inputs |
| [Linux man-pages](https://www.kernel.org/doc/man-pages/) | Linux interface documentation | Read about file/process behavior |

## Five-study-session route

1. Paths, files and permissions without privilege escalation.
2. Text search, sorting, pipes and redirection using invented CSV/logs.
3. Processes, system resources, environment and error diagnostics.
4. Python script execution from Bash and Windows BAT with exit codes.
5. SSH theory, host verification and read-only remote checks in an authorized lab.

**Definition of done:** be able to explain command inputs, outputs, side effects and failure paths. A production server, credentials and destructive commands are unnecessary.
