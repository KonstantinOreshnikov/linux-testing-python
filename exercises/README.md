# Practice / Практика

## English

1. Inspect a directory and produce a read-only inventory by extension and size.
2. Write a shell script that validates one input file and reports its line count.
3. Reimplement the inventory with `pathlib` and JSON output.
4. Create an SSH config entry using a placeholder host and document fingerprint verification.
5. Design a CI job that compiles Python and runs tests with least permissions.

## Русский

1. Проведите read-only инвентаризацию каталога по расширениям и размеру.
2. Напишите shell-скрипт, проверяющий один входной файл и считающий строки.
3. Повторите инвентаризацию через `pathlib` с JSON-выходом.
4. Создайте SSH config для условного хоста и опишите проверку fingerprint.
5. Спроектируйте CI-job для компиляции Python и тестов с минимальными permissions.
