# Linux, DevOps and Automation Lab / Лаборатория Linux, DevOps и автоматизации

A bilingual, safety-first path for Linux command-line work, shell and Python automation, SSH, containers and CI.

Двуязычный маршрут по безопасной работе в Linux, автоматизации на shell и Python, SSH, контейнерам и CI.

## English

The lab consolidates useful Linux and SSH learning themes into original documentation. Commands are examples, not permission to run destructive operations blindly: inspect targets, quote variables and prefer reversible changes.

## Русский

Лаборатория объединяет полезные темы Linux и SSH в оригинальную документацию. Примеры команд не являются разрешением бездумно запускать разрушительные операции: проверяйте цели, заключайте переменные в кавычки и предпочитайте обратимые изменения.
